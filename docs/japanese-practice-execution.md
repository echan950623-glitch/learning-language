## 授權與範圍

## 規則

- 支援基礎、進階、語態、複合表達、形容詞/名詞、敬語/口語，依已學進度確認啟用，未學內容不自動入題。
- 同一概念的理解/產出/應用分開保存練習項目、排程與證據；沿用 StudySession、/study、四種模式及 v2 排程。
- 題目用明確指定的形式/情境，完整答案與可接受答案比對；特殊動詞不按「る」猜分類。
- 保存題目版本、變體與原始答案；跨日輪換變體，提示/補考不當獨立成功。多題練習至少 5 個跨日到期無提示成功日且 3 個不同變體才穩定；題庫不足 3 題只承認已提供的有限範圍，单一詞練習不代表掌握整條規則。
- 同概念及同字不同形式的曝光隔至少 3 題；無法穿插仍可完成，近期曝光記有協助，不以相鄰題灌高熟練。跨裝置紀錄先按作答時間排序再判斷輪換／曝光。
- 錯誤分析只陳述能確認的錯誤，不從單一答案猜出動詞分類或其他能力。
- GPT 教練摘要是有来源的觀察，和正式作答證據分離，不改排程、不改歷史；預覽及使用者確認後才保存。
- 用現有 learning_metadata 做可選、可驗證的附加資料，舊紀錄不重寫、不猜測新能力；備份和同步保留新資料。

## 介面與流程

首頁 →「練習內容」→ 選變化/文法/助詞結構/搭配/閱讀 → 查看說明與樣題 → 確認已學並加入 → 今日學習或隨機練習 → /study → 有限補強 → 結算。

```text

[變化] [文法] [句子] [搭配] [閱讀]
搜尋內容／切換已加入或可加入
て形  未加入
  簡短規則、涵蓋動詞與例題
  [確認已學，加入產出練習]
已加入：產出 學習中／應用 尚未測過
[練已加入的內容] [今日學習]
```
