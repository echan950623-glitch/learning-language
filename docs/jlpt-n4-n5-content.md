# N4 目標／N5 複習內容

2026-10-10：依使用者「以 N4 為目標，N5 已學過」新增。這是原創備考內容，不是歷屆試卷，也不是官方完整考綱。JLPT 不公布完整詞彙／漢字／文法清單，級別標記是本專案的教學安排；不能由這批題目答對推論必定通過考試。

## 本次新增

| 範圍 | 內容組 | 題目變體 | 初始安排 |
| --- | ---: | ---: | --- |
| N5 複習 | 27 | 81 | 匯入預覽依使用者已學聲明設定 learnedConfirmed=true |
| N4 補強 | 56 | 169 | learnedConfirmed=false，待確認已學後才啟用 |
| 合計 | 83 | 250 | 不製造作答／掌握／排程紀錄 |

每組至少三題，沿用現有 LearningPractice、StudySession、題目快照、跨日複習及錯題流程。40 個詞彙各含漢字讀音、漢字寫法與繁中詞義練習；其餘為文法、情境選詞、日文近義句、詞彙用法、句子重組、文章文法與閱讀。各題含四個選項與繁中解析，可選文字或輸入原選項編號。四個選項由題目本身提供，不混入其他題目的答案。

N4 主要內容：經驗／列舉、打算／安排、義務與不必、可能形、能力／習慣變化、授受、四種條件接續、事先準備、完成／遺憾、嘗試、樣態／傳聞、目的、時間範圍與期限、同時動作、列舉理由、逆接、名詞化、意見、狀態變化、過度、建議／推量、間接疑問、被動／使役、常見敬語及自他動詞。

兩級皆有短文、段落理解與資訊檢索。文章涵蓋行程、借閱、通知、學習方法、購物、活動協助；著重時間改動、否定、指示詞、主旨、多重條件及例外。句子重組依正式題型回答★位置，不要求自由改寫。

所有選擇題只計為「理解」，不當作能自由產出日文或聽說能力的證據。題庫定義維持未學／未啟用；預覽 payload 的 learnedConfirmed 是另外的匯入設定。N5 已學不等於已掌握；N4 不能自動假設已學。

## 實際加入目前帳戶

這次只修改本機內容與產生匯入檔，尚未部署、未寫入正式帳戶。現有正式 MCP 支援自訂 practice，因此這些 JSON 可透過原工具新增，不必把 JSON 當成備份還原。

重新產生檔案：

```powershell
node scripts/export-jlpt-content.mjs
```

輸出在 `output/jlpt-content/`：N5 兩批、N4 三批，每批最多 20 組。檔案含完整自訂 practice，不依賴正式站尚未部署的新 catalogId。無 confirm=true、帳戶 ID、憑證、作答或排程。

在已登入正確帳戶的 GPT Web 連接器中，逐批附上 JSON，使用以下交接：

> 我的目標是 N4，N5 已學過。先用 get_study_profile 依 nextOffset 讀完已存內容，確認正確帳戶與重複內容。對附件 JSON 的 items 原樣呼叫 preview_practice_batch，顯示新增／重複／錯誤與樣題，讓我確認後才呼叫 add_practice_batch。N5 的 learnedConfirmed=true 依我已學聲明；N4 保持 false，不能擅自改成已學。每批最多 20 組；不要覆寫既有內容、清 outbox 或重設歷史／排程。檔案是新增預覽，不可用設定頁的備份還原匯入。

新增後核對 inserted、duplicates、errors；數量之外也核對題目與級別。未學 N4 可在現有內容編輯流程確認已學並啟用，再進入既有練習。上面的真實帳戶匯入、跨裝置同步及實體手機操作，本次尚未驗證。

## 官方題目與聽力

[官方題型及目前時間](https://www.jlpt.jp/e/guideline/testsections.html)：N4 文字語彙 25 分鐘、文法閱讀 55 分鐘、聽力約 35 分鐘；N5 為 20／40／約 30 分鐘。舊問題集印製時間較早，限時練習請依現在時間。

[官方公開問題集](https://www.jlpt.jp/e/samples/sampleindex.html)有 2012 與 2018 兩冊，各級題目選自實際考試，附答案、聽力腳本及音檔。這是公開的真題選集，不是逐年完整歷屆試卷。本專案不複製其題目或音檔，原創題型依[官方範例](https://www.jlpt.jp/e/samples/sample09.html)校準。

[官方 FAQ](https://www.jlpt.jp/e/faq/)說明不公布完整 Test Content Specifications；不應把自編級別詞表稱為官方必考清單。

聽力需另外練課題理解、重點理解、話語表達與即時應答。使用官方音檔先聽後答，再對答案／腳本；文字對話練習、朗讀或看到腳本後答對都不能替代聽力驗收。目前 App 的這批內容是文字題，未新增音訊播放器或聽力評分。

## 以 N4 為目標的使用順序

1. 先限時做一冊官方 N4 公開問題集，將錯誤分成文字語彙、接續、文章理解與聽力，保留答案，不只看總正確率。
2. 每天先做 N5 到期／錯題，再學 1～2 組 N4；看懂解析後逐項確認已學。每組有多個變體，不把當天重做答對當成長期保留。
3. 每週安排一次沒看過的閱讀與官方聽力練習；原創文字題練接續和排除干擾，官方資料練速度與音訊理解。
4. 若準備 2026-12-06 的考試，最後兩週用另一冊官方問題集限時檢查弱點，保留考場節奏與聽力練習時間。考試日期以[官方頁面](https://www.jlpt.jp/e/guideline/testsections.html)為準，所在地報名／場次另向主辦單位確認。

這批只收錄 40 個詞彙，不能替代完整詞彙、漢字課程或聽力訓練；應依官方問題集的錯題持續補缺。不是完整模擬考引擎，不提供官方尺度分數或保證合格。
