# 每日新字與複習分區

首頁的日文與英文「今日學習」都改為左右兩個入口。

- 新字：每個語言、每個台北學習日最多 50 個不同的新項目。內容不足時按實際數量安排；每日額度不因重整、換輪或跨裝置而重置。
- 複習：包含所有到期能力與已引入內容尚未補齊的能力，例如日文讀音。不套用每日 20 題、每輪題數、忙碌模式或每輪驗證題數的上限。
- 未到期的既有能力不會自動重複加入；已完成的每日單位仍沿用 `completedUnitKeys`，同輪錯題補強沿用原本 retry 規則。
- 新字和複習各自出題。同語言有進行中的 session 時，首頁先提供繼續或明確放棄，避免切換入口後把已完成作答丟掉。可以中途離開再繼續。

入口 URL 是 `/study?language=ja&area=new`、`/study?language=ja&area=review`，英文將語言改為 `en`。既有不帶 `area` 的網址與主題自主練習相容。

`dailyStudyAreas.ts` 以既有 DailyPlan 格式建立完整佇列、依當日保留的新項目分區。新字入口會將帳戶額度保存為 50，先同步偏好與既有 outbox，再走原本 `reserve_daily_plan`，不繞過雲端預約與帳戶隔離。離線／預約失敗時保留既有複習與錯誤原因，不使用未取得的雲端新字額度。

複習規則為初學後 1 天確認，再依上次通過時間間隔 3／5／7／14 天；完整通過約在第 1／4／9／16／30 天。無提示首答、跨日且到期才前進。提示後答對／部分答對保留階段並隔天確認；答錯重設為隔天重練，通過後從 3 天階段開始。同日補練、尚未到期的答對和同輪 retry 不會延長間隔。

最後 14 天驗證通過後，每個能力退出日常佇列。日文詞義與讀音各自驗證，全部完成才是整字熟練；英文還需直接辨義與至少兩個句中情境的跨日證據，最後一階會使用保留的驗證題。主動練習仍可出熟字，實際答錯會重新啟用該能力。沒有預設 60 天抽查，不會把永久不忘當作承諾。

既有到期日與作答歷史保留；下一次到期的正式作答開始套用新排程，不憑舊 streak 直接標成新規則完成。新 `reviewPolicy`／`reviewStage`／`reviewCompleted` 保存在既有 schedule JSON metadata，作答事件記錄採用的 policy，歷史 replay 保留原演算法。沒有資料表變更、正式 migration 或假造學習紀錄。Service worker 外殼快取版本為 v33。

驗證包含 50 個新字與 300 題到期複習的分流、日文缺讀音、新字不足、當日額度保存、英文獨立額度，以及 session 恢復。手機尺寸瀏覽器以獨立訪客測試資料確認兩語言入口、題數不受舊 5 題／忙碌偏好限制、重整與返回首頁續接；沒有操作正式帳戶或資料庫。
